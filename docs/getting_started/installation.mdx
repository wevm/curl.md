# Installation

Install the CLI using your preferred method.

## Package Managers

### npm

```sh
npm i -g curl.md
```

### Bun

```sh
bun i -g curl.md
```

## Install Script

Alternatively, use the install script:

```sh
curl -fsSL https://curl.md/install.sh | bash
```

## Verify Installation

After installing, verify it works:

```sh
curl.md --version
```
