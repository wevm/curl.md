# @curl.md/opencode

Turn websites into **optimized, low token output** inside **OpenCode**.

## Install

```sh
opencode plugin @curl.md/opencode
```

## Documentation

For full documentation, visit [curl.md/docs](https://curl.md/docs/plugins/opencode)
