# @curl.md/amp

Amp plugin for `curl.md`.

## Install

```sh
npx @curl.md/amp install
```

Successful installs print the Amp config path and create
`~/.config/amp/plugins/curlmd.ts`.

Amp currently starts with plugins disabled unless `PLUGINS` is set.
Launch it with:

```sh
PLUGINS=all amp
```
