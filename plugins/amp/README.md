# @curl.md/amp - URL to markdown for Amp

Turn websites into **optimized, low token output** to **supercharge your context**.

## Install

```sh
npx @curl.md/amp install --yes
```

To update:

```sh
npx @curl.md/amp@latest install --yes
```

## Documentation

For full documentation, visit [curl.md/docs](https://curl.md/docs/plugins/amp)
